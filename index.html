Using AU Calendar

Tap a day number to create an event. Tap any coloured event to read or edit it. Use the arrows to change months, or Jump to date to go straight to a year.

Events can span multiple days and can have an optional time, category and long notes. Search below the calendar to find them across all years.

Your last month is remembered when you reopen this same browser and website.

Back up downloads a JSON copy of your events. Restore reads that file back in; it replaces the current collection, so back up first.

For home-screen installation, use your browser's Add to Home screen or Install app option after opening a hosted HTTPS version. For offline use, first open the site while connected to the internet.
